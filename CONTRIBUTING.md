# Contributing

Thank you for improving the guide. Keep changes beginner-friendly, specific, and supported by current official documentation.

1. Open an issue describing the chapter and proposed correction.
2. Link the primary source that supports the change.
3. Create a focused branch and edit the matching file in `content/`.
4. Explain a technical term the first time it appears.
5. Run `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build`.
6. Open a pull request with screenshots for visible layout changes.

Do not include secrets, personal server addresses, copyrighted screenshots without permission, copied documentation, or redistributed mod files. Be respectful and follow the Code of Conduct.
