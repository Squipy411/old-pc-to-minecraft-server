# Code of Conduct

We want this project to be useful to people who are learning. Be patient, welcoming, and precise. Critique instructions and evidence—not people. Harassment, discrimination, intimidation, doxxing, sexualized conduct, and deliberate disruption are not acceptable.

Project maintainers may edit or remove contributions and participation that violate these expectations. Report conduct concerns privately to the repository owner through GitHub. Do not include personal or security-sensitive information in a public issue.
