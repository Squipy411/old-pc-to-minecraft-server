## Printable pre-install check

- [ ] Backup opened successfully on another computer
- [ ] Extra storage drives disconnected
- [ ] Target drive model and size written down
- [ ] Ethernet connected
- [ ] PC connected to reliable power
- [ ] Correct x86-64 ZimaOS USB inserted

> [!DANGER] Last chance before erasure
> The installer target is destroyed. If two drives look similar, shut down and physically disconnect the one you need to keep.

## Install click by click

1. At the ZimaOS menu, choose **Install ZimaOS**.
2. Select the target by matching both its model and capacity to your notes.
3. Read the confirmation screen. If it names the wrong drive, cancel.
4. Confirm installation only when the target is certain.
5. Wait without powering off the PC.
6. When prompted, remove the USB stick.
7. Choose restart or power off, then start the PC again.
8. Leave Ethernet connected during the first boot.

The current official ZimaSpace guide shows an installation menu, target selection, two confirmations, a progress screen, and a prompt to remove the USB. Button wording may differ by release.

## First boot

The first boot can take several minutes while ZimaOS prepares services. A quiet screen does not necessarily mean it failed. If the installer starts again, remove the USB and restart. If Windows returns, open the boot menu and select the newly installed ZimaOS drive; only then consider changing boot order.
