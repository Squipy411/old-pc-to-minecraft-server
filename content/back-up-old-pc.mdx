## Stop before the installer

> [!DANGER] The selected installation drive will be erased
> ZimaOS replaces the contents of the drive you choose. If a photo, document, password export, browser profile, game save, or licence file matters, copy it now and open the copy from another device before continuing.

## Find what matters

Check Desktop, Documents, Downloads, Pictures, Videos, music libraries, browser bookmarks, password-manager exports, email archives, game saves, tax records, and any folder created by another family member. Emptying the Recycle Bin is not a backup task; do not tidy the old PC until the verified copy exists.

1. Connect an external drive with enough free space.
2. Create a folder named with the PC name and today’s date.
3. Copy the important folders—do not move them.
4. Safely eject the drive.
5. Connect it to another computer and open several files.
6. Keep it disconnected during the ZimaOS installation.

## Identify every drive

In Windows, open **Settings → System → Storage → Disks & volumes** or **Disk Management**. Write down each drive’s model and approximate capacity. “476 GB” is normally a marketed 512 GB drive. A capacity is a clue, not proof; match the model too.

- [ ] Important files copied and opened elsewhere
- [ ] Installer target model and size written down
- [ ] Extra internal and external data drives disconnected if practical
- [ ] USB installer is clearly labelled
- [ ] Another person’s files checked

Disconnecting extra drives is the simplest protection against choosing the wrong target. If a drive cannot be disconnected, photograph the drive list and slow down at the selection screen.
