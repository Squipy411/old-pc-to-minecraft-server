## Use the official Community Edition image

Open the [official ZimaOS download page](https://www.zimaspace.com/zimaos/download) and choose **ZimaOS Community Edition** or follow its **Install Guide**. ZimaSpace’s current installation documentation points generic x86-64 users to the latest official release image.

The download should be an image, commonly ending in `.img` or arriving inside a compressed archive. The current official guide requires a generic **x86-64** PC, at least **25 GB** of target storage, UEFI boot, and Secure Boot disabled for installation. Check the release notes for a newer requirement before flashing.

> [!WARNING] Do not drag the image onto the USB
> A bootable image contains partitions and startup information. A flashing tool must write that structure to the whole USB stick. Ordinary copy and paste only stores the file.

## Before moving on

1. Confirm the browser address is `zimaspace.com` or the official release repository linked by ZimaSpace.
2. Confirm the filename indicates x86-64/amd64, not ARM.
3. Let the download finish fully.
4. Keep the official [ZimaOS installation guide](https://www.zimaspace.com/docs/zimaos/how-to-install-zimaos) open on a second device.

Do not download operating-system images from file mirrors, forum attachments, or video descriptions.
