## Make the problem reproducible

Helpers need versions, the first exact error, and which layer works. “It broke” forces them to guess. Redact public IPs, tunnel claim links, passwords, session cookies, access tokens, and email addresses.

1. Reproduce the problem once.
2. Note what changed immediately before it.
3. Copy the relevant console/log section as text.
4. State whether LAN joining works.
5. List the actual file versions, not “latest.”
6. Explain what you already tried and what changed.
