## Find the local address

Your router gives the server a local **IP address** using DHCP. The connected monitor may show an address such as `192.168.1.50`. Type it into a browser on another device connected to the same home network:

```text
http://192.168.1.50
```

That is only an example. Your address will be different. You can also try `http://zimaos.local`, use the current ZimaClient discovery option, or open your router/ISP app and find a newly connected wired device.

1. Keep the phone or computer on home Wi-Fi, not cellular data.
2. Type `http://` explicitly if the browser keeps forcing HTTPS.
3. Open the detected ZimaOS device.
4. Choose the language.
5. Create the initial administrator username and a unique password.
6. Save the dashboard address in your password manager or bookmarks.

## When the page does not load

Confirm the server is still powered on and finished booting. Reseat the Ethernet cable and check for link lights. Compare the monitor’s IP with what you typed. Disable cellular fallback temporarily. Guest Wi-Fi often isolates guests from wired devices. A mesh “IoT” network may do the same.

If the router shows the server but browsers cannot reach it, try another home device. Avoid exposing the dashboard to the public internet as a “fix.”
